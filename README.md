# حزمة الموقع ولوحة التحكم الإدارية — شركة نوكوم المحدودة (NoComm Ltd.)

نظام متكامل ومستقل تماماً يجمع بين:
1. **الموقع الرسمي الفاخر للواجهة الأمامية** لشركة **نوكوم المحدودة (NoComm Ltd.)**.
2. **خادم باك إند ولوحة تحكم إدارية كاملة (NoComm CMS)** مبنية بلغة **Python** وقاعدة بيانات **SQLite**.

---

## 🚀 كيفية التشغيل والوصول إلى لوحة التحكم

### 1. تشغيل الخادم (Python Server)
في مجلد المشروع، شغّل الأمر التالي:
```bash
python server.py
```

### 2. الروابط المباشرة:
* 🌐 **الموقع الرئيسي للزوار**: [http://localhost:3000](http://localhost:3000)
* ⚙️ **لوحة التحكم الإدارية (NoComm CMS)**: [http://localhost:3000/admin](http://localhost:3000/admin)

### 🔑 بيانات تسجيل الدخول الافتراضية للوحة التحكم:
* **اسم المستخدم**: `admin`
* **كلمة المرور**: `admin123`

## 🎛️ مميزات لوحة التحكم الإدارية (NoComm CMS)
1. **لوحة الإحصائيات (Overview Dashboard)**: متابعة فورية لعدد طلبات الأسعار والرسائل غير المقروءة والمنظومات النشطة.
2. **إدارة بيانات الشركة وهوية الهيرو**: تعديل الهواتف، البريد، العنوان، السجل التجاري، الرقم الضريبي، وعنوان الهيرو والنبذة التعريقية مباشرة.
3. **إدارة المنظومات والأنشطة (Services Catalog)**: إضافة وتعديل وحذف المنظومات والأنشطة الـ 8 وتغيير صورها وميزاتها وأيقوناتها.
4. **إدارة معرض المشاريع (Projects Showcase)**: إضافة وتعديل مشاريع الشركة وحالتها وعملائها.
5. **صندوق الوارد وإدارة العملاء (Leads & Inbox)**: تصفح وقراءة طلبات عروض الأسعار ورسائل الموقع، فلترة حسب الحالة (جديد/مقروء/مكتمل)، وتصدير كافة الطلبات بضغطة زر إلى ملف **Excel / CSV**.
6. **مكتبة الوسائط ورفع الملفات (Media Library)**: رفع صور وفيديوهات جديدة مباشرة إلى مجلد `PHOTO/` مع المعاينة الفورية ونسخ المسارات.
7. **العمل الاحتياطي الذكي (Offline Graceful Fallback)**: الموقع مصمم ليستمر بالعمل 100% وعرض البيانات الافتراضية حتى في حال إيقاف خادم الباك إند.
